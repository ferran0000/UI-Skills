# Module: Dense Enterprise Tools & AI Chat UI (`mod-pro-ai`)

対象: 管理画面、トレーディング/分析ダッシュボード、業務ツール、AIチャット・エージェントUI

## 1. 高密度データテーブル設計（NN/g / Dell Design System 準拠）
※ 一般向けWebの「広い余白・少選択肢」よりも、**一覧性・操作効率・比較容易性**を優先する例外領域。
- **PRO-01 列順と識別子**: 1列目にはシステムIDではなく人間が識別できる名称・タイトルを置き、比較頻度の高い列を隣接させる。
- **PRO-02 整列と数値フォーマット**:
  - テキストおよび定性的な数値（郵便番号・電話番号・ID）は **左揃え**。
  - **定量的な数値（金額・数量・割合）は右揃え＋小数点揃え＋`font-variant-numeric: tabular-nums`** とする。
  - **列ヘッダーの整列も配下のデータ列と一致させる**。
- **PRO-03 行の視認性・セマンティクス・アクション集約**:
  - `<table>` には `<caption>` と `<th scope="col|row">` を付与し、支援技術でも列・行の関係が伝わるようにする。
  - 標準のデータ表は **薄い水平線（装飾扱いの `var(--border-default)`）＋5〜10%程度の控えめなゼブラストライプ／ホバーハイライト** で視線を横に誘導し、ヘッダーを固定（`position: sticky` ＋ `scroll-padding-top` で `VIS-08` 準拠）する。超高密度な表のみグリッド線（縦横）を選ぶ。
  - 行ごとの複数アクションは末尾のアクションメニュー（ケバブメニュー等）へ集約する。
- **PRO-04 キーボードファーストとショートカット**: 頻出操作（検索 `Cmd/Ctrl+K`、保存、新規作成、行移動）にショートカットを割り当て、ツールチップやヘルプで発見可能にする。
- **PRO-05 フィルタと状態の永続化**: 適用中の絞り込み条件・ソート順はチップ等で明示し、1クリックでリセットでき、URLクエリ等で共有・復元可能にする。

### Good Pattern: 数値整列＆ヘッダー固定テーブルCSS
```css
.data-table th, .data-table td {
  padding: var(--space-2) var(--space-3);
  border-bottom: 1px solid var(--border-default); /* decorative row divider */
  text-align: left;
}
.data-table th.num, .data-table td.num {
  text-align: right;
  font-variant-numeric: tabular-nums;
}
.data-table thead th {
  position: sticky;
  top: 0;
  background-color: var(--bg-surface);
  color: var(--text-primary);
}
```

## 2. AIチャット・自律エージェントUI設計
- **AI-01 ストリーミングと制御権（ユーザー主導権）**:
  - 生成中はストリーミング表示（または処理ステップの可視化）を行い、レイアウトシフトを抑えつつ、いつでも押せる **「生成を停止（Stop）」ボタン** を常設する。
  - 出力後には **「再生成」「コピー」「編集して再送信」** を配置する。
- **AI-02 出典・根拠と不確かさの明示**:
  - 外部検索・ファイル参照を行った場合は、回答と紐づく出典リンク・参照元を明示する。
  - AIの推測・未検証情報・限界がある場合は、視覚的に区別できる注記や信頼度表現を用いて誤解を防ぐ。
- **AI-03 破壊的ツール実行前の承認（Human-in-the-Loop）**:
  - メール送信・ファイル削除・外部APIへの書き込みなど不可逆なアクションをAIが実行する前は、「実行内容のプレビュー＋承認/拒否ボタン」を挟む。
- **AI-04 失敗・中断時のグレースフルリカバリ**:
  - タイムアウトやレート制限エラー時に、ユーザーの入力プロンプトを保持したまま1クリックで「再試行」できる導線を維持する。
