# Module: Dense Enterprise Tools & AI Chat UI (`mod-pro-ai`)

対象: 管理画面、トレーディング/分析ダッシュボード、業務ツール、AIチャット・エージェントUI

## 1. 高密度データテーブル設計（NN/g / Dell Design System 準拠）
- **PRO-01 列順と識別子**: 1列目にはシステムIDではなく人間が識別できる名称・タイトルを置き、比較頻度の高い列を隣接させる。
- **PRO-02 整列と数値フォーマット**:
  - テキストおよび定性的な数値（郵便番号・電話番号・ID）は **左揃え**。
  - **定量的な数値（金額・数量・割合）は右揃え＋小数点揃え＋`font-variant-numeric: tabular-nums`** とする。
  - **列ヘッダーの整列も配下のデータ列と一致させる**。
- **PRO-03 行の視認性・セマンティクス・アクション集約**:
  - `<table>` には `<caption>` と `<th scope="col|row">` を付与する。
  - 標準のデータ表は **薄い水平線（`var(--border-default)`）＋5〜10%程度の控えめなゼブラストライプ／ホバーハイライト** で視線を横に誘導し、ヘッダーを固定（`position: sticky` ＋ `scroll-padding-top`）する。
  - 行ごとの複数アクションは末尾のアクションメニュー（ケバブメニュー等）へ集約する。
- **PRO-04 キーボードファーストとショートカット**: 頻出操作（検索 `Cmd/Ctrl+K`、保存、新規作成、行移動）にショートカットを割り当てる。
- **PRO-05 フィルタと状態の永続化**: 適用中の絞り込み条件・ソート順はチップ等で明示し、1クリックでリセットでき、URLクエリ等で復元可能にする。

## 2. AIチャット・自律エージェントUI設計
- **AI-01 ストリーミングと制御権（ユーザー主導権）**: 生成中はストリーミング表示を行い、いつでも押せる **「生成を停止（Stop）」ボタン** を常設し、出力後には **「再生成」「コピー」「編集して再送信」** を配置する。
- **AI-02 出典・根拠と不確かさの明示**: 外部検索・ファイル参照時は出典リンクを明示し、推測・未検証情報には視覚的に区別できる注記を添える。
- **AI-03 破壊的ツール実行前の承認（Human-in-the-Loop）**: 不可逆なアクションをAIが実行する前は、「実行内容のプレビュー＋承認/拒否ボタン」を挟む。
- **AI-04 失敗・中断時のグレースフルリカバリ**: エラー時にユーザーの入力プロンプトを保持したまま1クリックで「再試行」できる導線を維持する。
