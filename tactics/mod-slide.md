# Module: Presentation Slides — Markdown / Marp Outline (`mod-slide`)

対象: Markdown / Marp 形式で出力するプレゼンテーション構成案、ピッチデック、提案スライド原案  
（※ PowerPoint `.pptx` や Google Slides の直接レイアウト調整は機械判定の対象外＝`UNV-D1` として扱う）

## 1. Assertion-Evidence アプローチ（Penn State 研究 / Mayer 理論 準拠）
- **SLD-01 主張見出し（Assertion）**: 1スライドにつき1つの結論に絞り、スライドタイトル（`##`）は **1文で主張を言い切る要約文** にする（例: `## 2026年市場は前年比1.4倍へ拡大する`）。
- **SLD-02 視覚的証拠（Evidence）**: 本文エリアは主張を裏付ける図解・グラフ・表・写真の配置指示またはデータで構成し、情報ブロックは最大3〜4個に抑える。
- **SLD-03 スピーカーノートへの分離**: スライド上のテキストは箇条書き3〜5項目・各1〜2行以内に収め、口頭で説明する補足詳細・読み上げ原稿は HTML コメント（`<!-- Note: ... -->`）等のスピーカーノートへ分離する。

## 2. 視覚設計とアクセシビリティ基準（投影・画面共有前提）
- **SLD-04 フォントサイズと視認性**: 後方席・画面共有・弱視環境に備え、サンセリフ体・本文 **24pt以上**（注釈でも14pt以上）・高コントラスト（WCAG 2.2 AA）を指定する。
- **SLD-05 余白率の確保**: スライド面積の **30〜40% 以上** を余白として確保する構成（テキスト量の上限管理）にする。
- **SLD-06 色の制限と非色手がかり**: ベース色・メイン文字色・アクセント色（強調したい1点）の **3色以内** で設計し、色に加えてデータラベルや形状で意味を伝える。
- **SLD-07 データ可視化の選択**: 比較は表、推移は折れ線、構成比は棒グラフを選び、グラフには要点を示す代替テキスト（要約文）を添える。

### Good Pattern: Marp スライド構成案テンプレート
```markdown
---
marp: true
paginate: true
---

## 2026年市場は前年比1.4倍へ拡大する

- 法人向け導入が前年比 **+62%** で全体を牽引
- 既存顧客の継続率は **94%** を維持
- [図解: 2024〜2026年 市場規模推移の折れ線グラフ（2026年のみアクセント色）]

<!-- Note: ここでは具体的な導入社数の推移と、法人向けプラン改定の影響を口頭で補足する。 -->
```
