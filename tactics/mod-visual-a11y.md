# Module: Visual Hierarchy, Layout & Accessibility (`mod-visual-a11y`)

対象: Webサイト、LP、Webアプリ全般（HTML / CSS / UIコンポーネント）

## 1. 視覚的階層と余白（Refactoring UI 出力制約版）
- **A-1 色に依存しない階層成立**: 色相の違いだけで重要度を伝えない。グレースケールにしても情報の優先順位が分かるよう、**サイズ・ウェイト（400/500 vs 600/700）・余白**で差をつける。
- **A-4 近接の法則の数値化**: 関連要素間（グループ内）の余白を狭くし、別グループ間の余白は**グループ内の2倍以上**にする（例: グループ内 `8px` / グループ間 `16px〜24px`）。入力ラベルは対象フィールドの直上に密着させる。
- **A-5 枠線（ボーダー）の最小化**: 要素を区切るために安易な線を引かない。優先順位は **1. 余白 → 2. わずかな背景色差 (`bg-surface` / `bg-subtle`) → 3. 控えめなシャドウ → 4. 最小限のボーダー**。
- **A-6 トークン固定**: 余白は `4px/8px` スケール（`tokens/design-tokens.json`）、文字色は 2〜3 段階（`text-primary`, `text-secondary`, `text-muted`）に限定する。

## 2. カラー・コントラスト・ダークモード（WCAG 2.2 AA）
- **C-1 コントラスト比基準（WCAG 2.2 AA）**:
  - 通常テキスト: **4.5:1 以上**
  - 大きいテキスト（**18pt≒24px以上**、または**太字の14pt≒18.66px以上**）: **3.0:1 以上**
  - 非テキストUI部品（入力欄の枠線、アイコン、フォーカスリング等 / SC 1.4.11）: **3.0:1 以上**
- **C-2 色付き背景上の文字**: 色付き背景に薄いグレー文字を置かない（濁って視認性が落ちる）。`on-accent` 等の検証済みペアを使う。
- **C-5 ダークモード設計**:
  - 単純な色反転（`filter: invert` 等）や純黒 `#000000` × 純白 `#FFFFFF` の極端なコントラストを避け、深いスレート系背景（`#0F172A`）＋明度を抑えたオフホワイト（`#F8FAFC`）を使う。
  - ダークモード側でも全ペアのコントラスト比を個別に検証する。

## 3. セマンティックHTML・キーボード・モーション・レスポンシブ
- **C-4 フォーカス可視化**: `outline: none` の単独指定を禁止。`:focus-visible` で高コントラストなフォーカスリング（3:1以上）を必ず表示する。
- **C-6 セマンティックHTML & ARIA**:
  - ランドマーク（`<header>`, `<nav>`, `<main>`, `<footer>`）を適切に使う。
  - クリック可能な要素に `<div>` を使わず `<button>`（操作）または `<a href>`（遷移）を使う。
  - 装飾以外の `<img>` には必ず内容を表す `alt` 属性を付与する（装飾画像は `alt=""`）。
  - 見出しレベル（`h1`〜`h6`）を飛ばさない。
- **C-7 モーション配慮**: アニメーション実装時は `@media (prefers-reduced-motion: reduce)` で動きを抑制・無効化するフォールバックを必ず併記する。
- **C-8 レスポンシブ・モバイルファースト**: モバイル幅（375px）で横スクロールが発生しないこと。左右余白は最低 `16px` を確保する。
