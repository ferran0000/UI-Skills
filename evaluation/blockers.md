# Evaluation: Blocker Definitions, Coverage & Severity Rules

Phase 3 の自己評価で「修正ループを必須発動させる致命的欠陥（Blocker）」を具体項目として定義する。
**以下の `BLK-01`〜`BLK-07` に該当する場合のみ Blocker とする**。

## 1. Blocker リストと機械判定カバレッジ表

| ID | 対象 | 欠陥の具体定義 | 機械判定カバレッジ | 機械判定の限界（LLM/未検証で補完） |
| :--- | :--- | :--- | :--- | :--- |
| **BLK-01** | Web / 文書 / 画像 | **主要アクション／結論の不在・判読不能**: 画面・文書の冒頭を見ても「何の画面／文書か」「次に何をすべきか」が特定できない（生成画像での致命的な文字化け・主要UIの欠損を含む）。 | LLM判断のみ | 意味理解・視覚判読が必要なため機械判定不可 |
| **BLK-02** | Web / 画像 | **不可逆操作の無防備**: 削除・解約・課金確定などの破壊的操作に、確認ステップも Undo もなく、Primary と同等の位置・見た目で誤爆しやすい。 | LLM判断のみ | 操作の破壊性・導線意図の判定が必要 |
| **BLK-03** | Web / 画像 | **コントラスト比 WCAG 2.2 AA 未満**: 通常テキスト 4.5:1 未満、大文字 3.0:1 未満、UI境界・アイコン 3.0:1 未満。 | **一部可** | Webは同一ルール内・ローカル外部CSS・テーマ別変数・rgba合成を検査。画像は Pillow 利用可能時に `--sample-pair` / `--contrast-box` 指定領域を実測 |
| **BLK-04** | Web | **フォーム入力データの消失／ラベル欠落**: エラー時に入力値をリセットする設計、または `<label>` / `aria-label` 欠落。 | **一部可** | HTML上のラベル欠落は機械検出。エラー時リセット挙動はJS/LLM判断（画像時は `UNV-I1`/`UNV-I2`） |
| **BLK-05** | Web | **キーボード・アクセシビリティ破綻**: フォーカス消失、非セマンティッククリック要素・キー操作ハンドラ欠如、重要画像の `alt` / リンクのアクセシブルネーム欠落、モーダルのフォーカストラップ欠如。 | **一部可** | 静的HTML/CSSの欠陥は機械検出。モーダル動的挙動・タブ順はLLM/実機確認（画像時は `UNV-I1`/`UNV-I2`） |
| **BLK-06** | Web / 文書 / 画像 | **ダークパターン／虚偽誘導**: 確認シェイミング、意図的な解約妨害、根拠のない偽の緊急表示が含まれる。 | LLM判断のみ | 文言・UI意図の倫理判定が必要 |
| **BLK-07** | 文書 / Web | **見出し構造の破綻**: 見出しレベルがスキップ（`h1`→`h3` 等）している、またはページ開始見出しが `h3` 以降になっている。 | **機械判定可** | HTML/Markdown の見出し階層を機械検出（画像時は `UNV-I1`） |

## 2. 重大度区分と対応ルール
- **Blocker**: リリース不可。Phase 3 の修正ループ（最大2回）で解消する。
- **Major**: 体験を大きく損なう欠陥。原則修正するが、正当な理由があれば理由を明記して残すことも可。
- **Minor**: 改善するとさらに良くなる点。修正は任意。
