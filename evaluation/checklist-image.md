# Evaluation Checklist: Image UI Mockups & Screenshots (`checklist-image`)

Phase 3 でのみロードする。JPEG / PNG 形式のアプリ画面案・UIモックアップ・スクリーンショット専用。

## 区分1: 機械判定（`scripts/ui_ux_checker.py` - Pillow利用可能時）
- [ ] **CHK-I1 解像度・比率・余白概算**: 対象デバイス比率に対して極端な低解像度や崩れた縦横比になっていないか。（`IMG-01`, `IMG-05`）
- [ ] **CHK-I2 指定領域の実測コントラスト比**: `--sample-pair` / `--contrast-box` で主要テキスト・CTAボタン・入力枠のコントラスト比が WCAG 2.2 AA を満たすか実測する。（`BLK-03`, `IMG-06`）
- [ ] **CHK-I3 代表色パレット整合性**: 抽出された上位パレットが意図したライト／ダークトーン・ブランド色と整合しているか。（`IMG-03`）

## 区分2: AI視覚原則判断（共通6原則 `PRN-1`〜`PRN-6`）
- [ ] **PRN-1 認知負荷の最小化**: 何の画面か・主行動（Primary CTA）が即座に分かるか。（`BLK-01`, `IMG-02`）
- [ ] **PRN-2 一貫性と慣習の尊重**: プラットフォーム慣習および画面内の一貫性。
- [ ] **PRN-3 状態の可視性**: 選択中タブ・現在地・ステータス・単位の明瞭さ。
- [ ] **PRN-4 エラー防止と可逆性**: 破壊的操作の隔離。（`BLK-02`）
- [ ] **PRN-5 視覚階層・近接・生成品質**: 余白バランス、非色手がかり、文字化け・見切れ・重なりの有無。（`IMG-05`, `IMG-06`, `IMG-07`）
- [ ] **PRN-6 倫理とユーザー主導権**: 戻る／閉じる導線とダークパターン不在。（`BLK-06`）

## 区分3: 未検証（JPEG / PNG 静止画単体では判定不可）
- [ ] **UNV-I1 セマンティック構造と支援技術**
- [ ] **UNV-I2 キーボード・フォーカス・動的状態遷移**
- [ ] **UNV-I3 実機物理サイズと体感パフォーマンス**
