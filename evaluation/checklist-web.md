# Evaluation Checklist: Web & UI (`checklist-web`)

Phase 3 でのみロードする。全観点を「機械判定」「LLM原則判断（共通6原則）」「未検証」の3区分で評価する。

## 区分1: 機械判定（`scripts/ui_ux_checker.py`）
- [ ] **CHK-W1 コントラスト比**: 評価対象ペアが WCAG 2.2 AA（通常4.5:1 / 大文字3.0:1）を満たすか。（`BLK-03`, `VIS-05`）
- [ ] **CHK-W2 ターゲットサイズ**: インタラクティブ要素の `width`/`height`/`min-width`/`min-height` が 24×24px 以上か。（`INT-02`）
- [ ] **CHK-W3 フォーカスリング保護**: `:focus` / `:focus-visible` で代替なしの `outline: none` や透明な `box-shadow` がないか。（`BLK-05`, `VIS-08`）
- [ ] **CHK-W4 セマンティック＆属性**: `<img>` の `alt` 付与、空画像リンクのアクセシブルネーム、非セマンティッククリック要素のキー操作、フォーム入力と `<label>` の紐付け、見出しレベル連続性。（`BLK-04`, `BLK-05`, `BLK-07`, `VIS-09`）
- [ ] **CHK-W5 自己完結したリンク文言**: 汎用文言のみのリンクが存在しないか。（`DOC-07`）
- [ ] **CHK-W6 トークン準拠（新規生成 `--strict-tokens` 時）**: `:root` 定義外の直書き `hex` カラーが残っていないか。（`VIS-04`）

## 区分2: LLM原則判断（共通6原則 `PRN-1`〜`PRN-6`）
- [ ] **PRN-1 認知負荷の最小化** / **PRN-2 一貫性と慣習の尊重** / **PRN-3 状態の可視性とフィードバック** / **PRN-4 エラー防止と可逆性** / **PRN-5 視覚階層と近接関係** / **PRN-6 倫理とユーザー主導権**

## 区分3: 未検証
- [ ] **UNV-W1 実レンダリングでの視覚階層・バランス**
- [ ] **UNV-W2 実測パフォーマンス・体感速度**
- [ ] **UNV-W3 実機・支援技術検証**
