# Evaluation Checklist: Web & UI (`checklist-web`)

Phase 3 でのみロードする。全観点を「機械判定」「LLM原則判断（共通6原則）」「未検証」の3区分で評価する。

## 区分1: 機械判定（`scripts/ui_ux_checker.py`）
- [ ] **CHK-W1 コントラスト比**: 評価対象ペアが WCAG 2.2 AA（通常4.5:1 / 大文字3.0:1）を満たすか。テーマ別変数・rgba合成・外部CSS含む。（`BLK-03`, `VIS-05`）
- [ ] **CHK-W2 ターゲットサイズ**: インタラクティブ要素の `width`/`height`/`min-width`/`min-height` が 24×24px 以上（主要タップ対象は 44×44px 推奨）か。（`INT-02`）
- [ ] **CHK-W3 フォーカスリング保護**: `:focus` / `:focus-visible` で代替なしの `outline: none` や透明な `box-shadow` がないか。（`BLK-05`, `VIS-08`）
- [ ] **CHK-W4 セマンティック＆属性**: `<img>` の `alt` 付与、空画像リンクのアクセシブルネーム、非セマンティッククリック要素のキー操作、フォーム入力と `<label>` の紐付け、見出しレベル連続性。（`BLK-04`, `BLK-05`, `BLK-07`, `VIS-09`）
- [ ] **CHK-W5 自己完結したリンク文言**: 汎用文言のみのリンクが存在しないか。（`DOC-07`）
- [ ] **CHK-W6 トークン準拠（新規生成 `--strict-tokens` 時）**: `:root` 定義外の直書き `hex` カラー（`border`/`box-shadow` 含む）が残っていないか。（`VIS-04`）

## 区分2: LLM原則判断（共通6原則 `PRN-1`〜`PRN-6` に基づく証拠付き評価）
- [ ] **PRN-1 認知負荷の最小化**: タイトル・冒頭要素・Primaryボタンから目的と次の行動が読み取れるか。1ビューポートに Primary が集中しているか。（`BLK-01`, `INT-01`）
- [ ] **PRN-2 一貫性と慣習の尊重**: 既存DSや一般的なWeb慣習に沿っているか。同じ機能に同じ見た目・言葉が使われているか。（`VIS-04`, `VIS-09`）
- [ ] **PRN-3 状態の可視性とフィードバック**: Ideal / Loading / Empty / Error / Success の必要状態が設計され、1秒超の処理へのフィードバック方針があるか。（`INT-10`, `INT-11`）
- [ ] **PRN-4 エラー防止と可逆性**: 破壊的操作が隔離され、確認または Undo があるか。エラー文言は具体的（要件＋直し方）で入力値を保持するか。（`BLK-02`, `BLK-04`, `INT-03`, `INT-07`, `INT-08`）
- [ ] **PRN-5 視覚階層と近接関係（コード構造上）**: 色以外の要素でも階層が成立するか。グループ間余白 ＞ グループ内余白になっているか。モーダルやstickyヘッダーのフォーカス配慮があるか。（`VIS-01`, `VIS-02`, `VIS-08`, `VIS-10`）
- [ ] **PRN-6 倫理とユーザー主導権**: ダークパターンがなく、戻る・キャンセル・停止がいつでもできるか。（`BLK-06`, `INT-12`, `AI-01`）

## 区分3: 未検証（コードだけでは判定不可 — 必ず明示する）
- [ ] **UNV-W1 実レンダリングでの視覚階層・バランス**: 実際の画面上での視線誘導、意図しない折り返し・要素重なり、チェッカーがスキップした継承色ペアの視認性。
- [ ] **UNV-W2 実測パフォーマンス・体感速度**: 実環境での応答時間（100ms / 1秒基準）やスクロールの滑らかさ。
- [ ] **UNV-W3 実機・支援技術検証**: モバイル実機での片手操作性、スクリーンリーダーでの読み上げ順・モーダル挙動。
