# Evaluation Checklist: Document & Slides (`checklist-doc`)

Phase 3 でのみロードする。Markdown文書・仕様書・スライド用。

## 区分1: 機械判定（`scripts/ui_ux_checker.py` または静的検査）
- [ ] **M-D1 見出し階層の連続性**: `#` → `##` → `###` の順でスキップがないか。（`B-07`）
- [ ] **M-D2 壁テキストの検出**: 見出しや箇条書き・表の区切りなく、極端に長い段落（例: 400文字超の連続ベタ打ち）が存在しないか。（`B-07`）
- [ ] **M-D3 汎用リンク文言の排除**: `[こちら](...)`、`[詳細](...)`、`[クリック](...)` 等の文言がないか。（`B-7`）
- [ ] **M-D4 装飾の過剰使用**: 太字と斜体の重複（`***...***`）や、下線タグ（`<u>`）の非リンク使用がないか。（`B-6`）

## 区分2: LLM原則判断（文書・スライドUX原則）
- [ ] **P-D1 結論先出し（逆ピラミッド）**: 文書・各セクションの冒頭で、対象読者・目的・結論が即座に分かるか。（`B-01`, `B-2`）
- [ ] **P-D2 スキャナビリティ（レイヤーケーキ）**: 見出しだけを通読したときに文書全体の骨格が把握できるか。見出し・箇条書きがキーワードから始まっているか。（`B-1`, `B-3`）
- [ ] **P-D3 文脈に応じた情報密度**: 一般文書は簡潔か（3文目安）、仕様書・マニュアルでは網羅性を保ちつつ表や箇条書きでチャンク化されているか。（`B-4`）
- [ ] **P-D4 用語の一貫性と読者言語**: 読者にとって不要な内部用語・表記揺れ（全角半角の混在等）がないか。（`B-8`）
- [ ] **P-D5 スライド固有（スライド時のみ）**: 1スライド1メッセージが守られ、タイトルが結論要約になっているか。（`S-1`, `S-3`）

## 区分3: 未検証（テキストのみでは判定不可 — 必ず明示する）
- [ ] **U-D1 表示環境での実レンダリング**: 実際のビューア（GitHub / Notion / PDF / プロジェクター等）での改行位置、表の横はみ出し、フォント視認性。
- [ ] **U-D2 対象読者の理解度テスト**: 実際の想定読者が迷わず目的を達成できるか。
