# Evaluation Checklist: Document & Slides (`checklist-doc`)

Phase 3 でのみロードする。Markdown文書・仕様書・Marpスライド構成案用。共通6原則（`PRN-1`〜`PRN-6`）へマッピングして評価する。

## 区分1: 機械判定（`scripts/ui_ux_checker.py`）
- [ ] **CHK-D1 見出し階層の連続性**: `#` → `##` → `###` の順でスキップや `h3` 以降からの開始がないか。（`BLK-07`, `DOC-01`）
- [ ] **CHK-D2 壁テキストの検出（Major）**: 見出しや箇条書き・表の区切りなく、極端に長い段落（URL除外後: 日本語一般400字超 / 仕様書 `--doc-type spec` 800字超 / 英語150語超）が存在しないか。（`DOC-04`）
- [ ] **CHK-D3 自己完結したリンク文言（Major）**: 汎用的なリンク文言（例: `[こちら](...)` や `[詳細はこちら](...)`）が残っていないか。（`DOC-07`）
- [ ] **CHK-D4 装飾の節度（Minor）**: 太字と斜体の重複（例: `***強調***`）や、下線タグ（`<u>`）の非リンク使用がないか。（`DOC-06`）

## 区分2: LLM原則判断（共通6原則 `PRN-1`〜`PRN-6` の文書・スライド適用）
- [ ] **PRN-1 認知負荷の最小化（逆ピラミッド＆密度）**: 文書・各セクション冒頭で目的と結論が即座に分かるか。文脈に応じた長さ・チャンク化がされているか。（`BLK-01`, `DOC-02`, `DOC-04`）
- [ ] **PRN-2 一貫性と慣習の尊重**: 読者の言葉を使い、用語・表記（英数字半角・和文約物全角）が一貫しているか。（`DOC-08`）
- [ ] **PRN-3 状態の可視性（前提・範囲の明示）**: 対象読者・前提条件・更新状況・未確定事項（推測や限界）が明確に示されているか。（`AI-02`）
- [ ] **PRN-4 エラー防止（誤読・誤操作の防止）**: 手順書や仕様書で危険な手順・注意点・復旧手順が実行前の位置に明示されているか。
- [ ] **PRN-5 視覚階層とスキャナビリティ**: 見出しだけを通読して骨格が把握でき（レイヤーケーキ）、先頭にキーワードが配置されているか。スライド時は Assertion-Evidence になっているか。（`DOC-01`, `DOC-03`, `SLD-01`, `SLD-02`）
- [ ] **PRN-6 倫理と読者主導権**: 誇張や虚偽の緊急煽り（ダークパターン）がなく、読者が判断に必要な根拠・出典へ辿れるか。（`BLK-06`）

## 区分3: 未検証（テキストのみでは判定不可 — 必ず明示する）
- [ ] **UNV-D1 表示環境での実レンダリング**: 実際のビューア（GitHub / Notion / PDF / Marp投影）での改行位置、表の横はみ出し、フォント視認性。
- [ ] **UNV-D2 対象読者の理解度テスト**: 実際の想定読者が迷わず目的を達成できるか。
