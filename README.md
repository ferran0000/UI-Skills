# UI/UXデザインのAIスキル

AIに「見た目と使いやすさの判断基準」を教えるスキルです。Webサイト、アプリの画面、資料、ドキュメント、フォームなどを作ってもらうときや、既存のものを見直してもらうときに、AIが自動でデザインのルールに沿って動くようになります。

専門知識がなくても、「ちゃんと読みやすくて使いやすいもの」を作りやすくなるのが一番の強みです。

## かんたん導入（AIチャットに頼むだけ）

使っているAIチャットに、次のように伝えてください。

> https://github.com/ferran0000/UI-Skills を読んで、このスキルを今後の作業で使えるように設定して

> [!NOTE]
> AIがGitHubのページを読めない環境では、この方法は使えません。その場合は、このリポジトリのZIPをダウンロードして、AIの設定画面からスキルとして登録してください。

## このスキルでできること

- **見た目の「なんとなく変」を、具体的に直せる**: 文字と背景の色の見やすさ、文字の大きさ、余白の揃え方などを、根拠つきで指摘します。
- **最初から整った形で作れる**: 色・余白・文字サイズを決まった組み合わせで使うので、デザインに詳しくなくても、まとまりのある画面や資料になります。
- **誰にとっても使いやすいことを重視**: 目が見えにくい人や、操作に慣れていない人でも使えるよう、国際的なアクセシビリティ基準（WCAG 2.2 AA）に沿って確認します。
- **既存物の見直しは「まず診断」**: いきなり全部作り直すことはしません。問題点を重要度順に並べたレポートを出し、どこまで直すかを一緒に決められます。

### 対応している作業

- Webサイト、ランディングページ、Webアプリ
- フォーム、業務画面、テーブルなどの操作画面
- AIチャットの画面
- Markdownの文書、仕様書、マニュアル
- プレゼンのスライド

### 頼み方の例

- 「このLPのデザインを見て、改善点を優先度順に教えて」
- 「社内向けの申請フォームを作って。入力ミスが減るようにしてほしい」
- 「この仕様書を読みやすく整えて」

## 技術者向けの情報

### 仕組み

1. **3層構成**
   - **戦術（`tactics/`）**: 作るときに適用する具体的なルールとパターン
   - **評価（`evaluation/`）**: 完成後の自己評価で使うチェックリスト。根拠のない「問題なし」は認めない運用です
   - **機械判定（`scripts/ui_ux_checker.py`）**: コントラスト比、見出しの階層、属性、トークンからの逸脱などを、AIの印象ではなく計算で検査します
2. **優先順位**: `法令・WCAG 2.2 AA > ユーザーの明示要件・既存デザインシステム > 6つの原則 > 個別テクニック`
3. **3区分の判定**: すべての評価項目を「機械判定」「AIによる原則判断」「未検証（コードだけでは判定できない）」に分けます。
4. **作成と見直しの分離**: 既存物の見直しでは、勝手に全面的なリデザインをせず、まず診断レポートを出します。

### ディレクトリ構成

```text
.
├── SKILL.md                         # スキル本体（ルーター・優先順位・実行フロー）
├── tokens/
│   └── design-tokens.json           # 4/8pxのスケールと、WCAG 2.2 AAで検証済みの色の組み合わせ
├── tactics/
│   ├── mod-doc.md                   # 文書・Markdown・日本語の組版（DADS準拠）
│   ├── mod-visual-a11y.md           # 視覚階層・余白・色・WCAG 2.2・ダークモード
│   ├── mod-interaction-forms.md     # ボタンの階層・フォーム・5つの状態・ダークパターン回避
│   ├── mod-slide.md                 # プレゼンスライドの設計
│   └── mod-pro-ai.md                # 業務向けの高密度UI・テーブル・AIチャットUI
├── evaluation/
│   ├── blockers.md                  # 重大な欠陥の一覧（B-01〜B-07）と重大度の定義
│   ├── checklist-web.md             # Web・UI向けの3区分チェックリスト
│   └── checklist-doc.md             # 文書・スライド向けの3区分チェックリスト
├── scripts/
│   └── ui_ux_checker.py             # 外部ライブラリ不要（Python標準ライブラリのみ）の機械判定チェッカー
└── tests/
    ├── run_tests.py                 # 検出率と誤検知のテスト
    └── fixtures/                    # 欠陥を埋め込んだサンプルと、問題のない参照サンプル
```

### 機械判定チェッカーの使い方（Python 3.9以上）

```bash
# HTML・CSS・Markdownを検査
python3 scripts/ui_ux_checker.py path/to/target.html

# JSON形式で出力（AIエージェントとの連携用）
python3 scripts/ui_ux_checker.py path/to/target.html --json

# デザイントークンの色の組み合わせ自体を検証
python3 scripts/ui_ux_checker.py --check-tokens tokens/design-tokens.json
```

### テスト

```bash
python3 tests/run_tests.py
```
